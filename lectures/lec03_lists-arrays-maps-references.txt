Your computer stores information as memory
It is stored in bits which are either 1 or 0
It is basically converting binary to base 10 or another base
The Java interpreter needs datatypes so that it can use a bit sequence to identify a certain value
When you declare a variable of a certain type in Java:
Your computer sets aside exactly enough bits to hold a thing of that type
Java creates an internal table that maps each variable name to a location
Java does not write anything into the reserved boxes of a certain variable
For safety, Java will not let you access a variable that is uninitalized
For any variables, if we are given y and x, and we state y = x, then y = x copies all the bits from x into y, meaning that if we change x or y neither has an effect
